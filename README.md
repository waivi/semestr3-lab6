# Лабораторная работа: Базы данных (PostgreSQL)

__Задание к работе:__ Создать базу данных (БД) и таблицы в СУБД PostgreSQL,интегрировать базу данных в программу, написать запросы к базу данных. Тема базы данных и содержимое таблиц определяется студентомсамостоятельно, в данном случае тема кинофильмы.<br>

Необходимо:<br>
Создать базу данных (БД) и таблицы в СУБД PostgreSQL<br>
Написать и отладить программу решения задачи (С++, Go или Rust).  <br>
Интегрировать базу данных (БД) в программу. <br>
Написать запросы к таблицам. <br>
Протестировать работу программы на различных исходных данных. <br>
Продемонстрировать работу с СУБД PostgreSQL на примере написанной программы.
